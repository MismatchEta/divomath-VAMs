# Hosting divoVAM on a web server

This an example for a basic use of the generated `divoVAM.html` deployed to a web server. `index.html` provides a way to configure the URL parameters with a simple GUI. From this the actual URL is generated.

```bash
root
  ├─ index.html
  ├─ divoVAM.html
  ├─ freehand-drawing.js # required for drawing overlay
  └─ style.css
```
