# divoVAM

CindyJS widgets for mathematics education — interactive manipulatives ("virtuelle
Arbeitsmittel", VAM) written in CindyScript and deployed two ways: as a component
inside the [divomath](https://divomath-nrw.de) platform, and as a standalone HTML
page.

Current build: see [src/BUILD](src/BUILD), every build counts it up.


## The two deliverables

One source tree, two targets. `tools/build.py` produces both from `src/`:

| Output | Goes to | What it is |
|---|---|---|
| `out/divoVAM.html` | `abako.dzlm.de/cindy/vam/` | Self-contained page, configured through URL parameters |
| `out/freehand-drawing.js` | next to the HTML | Pen overlay, only loaded with `?draw` |
| `out/divoVAM.cdyjs` | divomath import | Module form, configured through the divomath editor |
| `out/img/` | `abako.dzlm.de/cindy/divomath/img/` | Icons the `.cdyjs` loads |
| `out/divoVAM.cdy` | — | By-product to open in Cinderella, see [Cinderella](#cinderella) |

Which widget is shown is a parameter, not a separate file — one build carries all
of them.

## Widgets

- `distributive`: Rectangular array model
- `divisors`: Division and remainders
- `numbercards`: Place value understanding
- `percentagebar`: Just an interactive percentagebar
- `strapwork`: Recognizing patterns
- `thales`: Thales' theorem and its inverse

Two more are under construction but unfinished and should not be used in production:
- `doublenumberline`
- `localderivate`.

## Requirements

- **Python 3.8** or later — no third-party packages, standard library only
- **CindyJS 0.8** — not vendored; the page loads it from `cindyjs.org/dist/v0.8/`,
  so checking a build needs an internet connection
- **Cinderella 3.0**, build 2131 or later — optional, only to open the generated `.cdy`
- **Firefox** — optional, only for the [screenshot comparison](#screenshot-comparison)

## Build

```bash
python3 tools/build.py
```

The full loop:

1. Edit the scripts in `src/cindyscript/` with any text editor
2. `python3 tools/build.py`
3. Check the result in the browser: `out/divoVAM.html?vam=<name>`
4. Commit, including `src/BUILD`
5. Upload the contents of `out/`

The build stops with a message, before writing anything, when the sources do not
fit together: a script file that is not in the manifest, a manifest entry without
file, a missing placeholder in the template. A build that stops does not count.

### Scripts and the manifest

Every file in `src/cindyscript/<event>/` is one script of that event. Its file
name without `.cindyscript` is its **label**, the name Cinderella shows for it.
`src/manifest.json` lists the labels of every event in the order they run:

```json
{
  "Init": ["[FUN] Divomath", "[FUN] Debug Logging", "...", "[FW] Init end"],
  "Draw": ["[FW] global drawing"]
}
```

To add a script, create its file and add its label to the manifest at the
position where it has to run. Labels must not contain characters Windows forbids
in file names (`< > : " / \ | ? *`).

### Options

| Flag | Effect |
|---|---|
| `--out DIR` | Output directory (default `out`) |
| `--img-base URL` | Base URL the `.cdyjs` loads icons from |
| `--rect A,B,C,D` | `visibleRect` written into the `.cdyjs` |
| `--force` | Build even if `out/divoVAM.cdy` was changed in Cinderella, throwing those changes away |

### Cinderella

`out/divoVAM.cdy` opens in Cinderella like any construction. Changes made there
are taken back into `src/` with

```bash
python3 tools/build.py unpack
```

which mirrors the file into `src/`: changed scripts are overwritten, removed ones
deleted, the manifest rewritten. `git diff` shows what happened. To protect work
in progress, `unpack` refuses while the files it would touch have uncommitted
changes, and the build refuses to overwrite an `out/divoVAM.cdy` that was changed
in Cinderella until `unpack` has run.

### Tests

```bash
python3 tools/test_build.py
```

Run them after changing `tools/build.py`. They work on a copy of `tools/` and
`src/` in a temporary folder, so the repo stays untouched.

### Screenshot comparison

```bash
python3 tools/screenshots.py save      # e.g. after an upload: remember how every widget looks
python3 tools/screenshots.py compare   # before the next one: did anything change?
```

Opens every finished widget in a headless Firefox and compares the screenshot
pixel by pixel with the stored one. References are kept in `.local/screenshots/`
(not versioned); a differing shot stays next to its reference as
`<widget>.new.png`. `--vam a,b` limits the widgets, `--query "rect=classic"`
compares another view.


## URL parameters (standalone build)

Widget parameters are documented in [docs/doc-german.md](docs/doc-german.md).
The ones below belong to the page itself and are handled in `src/template.html`,
which also holds the `rect` presets:

| Parameter | Effect |
|---|---|
| `?vam=<name>` | Which widget to show |
| `?full` | Canvas fills the browser window |
| `?rect=divomath` | 24.5 × 18.9 world units (default) |
| `?rect=classic` | 38.2 × 22.1 |
| `?rect=wide` | The viewport of the former `divoVAM-full.html` |
| `?rect=a,b,c,d` | Custom rect `[left, top, right, bottom]` |
| `?draw` | Freehand pen overlay, plus `drawpen`, `drawerase`, `drawpos`, `drawdir`, `drawmoveable` |

There is a form-based link generator for these at
<https://abako.dzlm.de/cindy/vam/>. That page has to be updated by hand 
when new parameters are added.
